# MIDASX Sales Playbook

Sales enablement assets for the MIDASX Calculator product (Vijya Fintech).
Focus: closing **Arjun (Digital-Native New MFD)** and **Priya (Ambitious Growth MFD)**.

## Files

| File | Purpose | Format |
|---|---|---|
| `MFD-Personas.md` | All 5 MFD personas — pains, triggers, objections, plan fit, disqualifiers | Markdown |
| `Sales-Closure-Tactics.md` | Full closure methodology — 5-stage cycle, discovery, demo, close, templates, metrics | Markdown |
| `onepager-arjun.html` | Printable A4 field one-pager for Arjun (AI Only ₹25k) | HTML (print-ready) |
| `onepager-priya.html` | Printable A4 field one-pager for Priya (Pro+AI ₹75k) | HTML (print-ready) |
| `objection-flashcards.html` | Mobile-first flippable objection-handling card deck | HTML (touch/swipe) |

## How to use

- **Before a meeting:** Open the relevant one-pager and skim. Print 2-up A4 if you want it on paper.
- **During a meeting:** Open `objection-flashcards.html` on your phone (filter by persona tab). Swipe / tap to flip — Q on front, your move on back.
- **After a meeting:** Update the persona doc with anything new you heard. The objection list is meant to grow.
